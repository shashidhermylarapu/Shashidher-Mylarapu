# Shashidher Mylarapu — Portfolio

React + Vite portfolio with a monochrome, type-led design: preloader word ring,
pinned manifesto whose letters fall with Matter.js physics, a Three.js gallery
room that projects each work on a screen, expanding expertise columns, and a
contact form. Smooth scrolling with Lenis + GSAP ScrollTrigger.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- All copy lives in `src/data.js` (works, about text, expertise, credentials).
- Photo: `public/shashidher.jpg` (shown in black and white via CSS).
- The contact form opens the visitor's email app (no backend).
